# Blog

Site URL: https://rumple.github.io/blog (repo must be named `blog`).

To publish: add `_posts/YYYY-MM-DD-title.md` starting with

    ---
    title: "Your title"
    ---

then write Markdown below it, commit, and `git push`. GitHub Pages builds the site.
Set the repo's Settings > Pages > Source to "Deploy from a branch" (main, / root).
